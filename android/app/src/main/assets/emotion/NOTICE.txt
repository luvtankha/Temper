The model card declares the MIT license. Tokenizer vocabulary/merges accompany
that RoBERTa model. Verified public weights are bundled in this APK and prepared
in private app storage on user request, without internet. Source builds fetch the
pinned weights if no verified local model path is supplied. A legacy missing-asset
download fallback shares only a network address, never chat text. This app has no
affiliation with the model author.

English Reddit-trained model; live dialogue and Hinglish accuracy are not
validated. Model scores are independent sigmoid outputs, not proof of emotion.
The Android app maps annoyance to frustration and fear/nervousness to concern.
Direction uses a small fictional-data-trained context pilot in version 0.46.0.
It is not independently human-validated. Emotion-bar weights are unchanged.
Compiled tokenizer.bin derives exactly from the pinned public vocabulary/merges.
