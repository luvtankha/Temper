# Phase 44 — Continuous analysis and movable companion

1. Objective: keep the selected live analysis session running through keyboard/composer movement and allow the user to drag the companion across the screen.
2. Repository: clean Phase 43 candidate at 6b80a15, version 0.43.0; the latest APK is installed on the test phone. User movement instructions supersede the historical fixed bottom-left placement requirement.
3. Completed phases: 00–19 foundation and 20–43 Android overlay, local model, consumer and optional rated-feedback work remain preserved.
4. Build/test baseline: 78 backend tests, 19 Android JVM tests, native foundation/consumer checks and aligned debug APK/unsigned release AAB passed Phase 43. No current live-chat result is assumed.
5. Architecture: selected-conversation Accessibility capture feeds bounded on-device analysis. The generic companion is already draggable; the active-analysis overlay currently replaces it with a fixed companion. Keyboard window events and transient missing anchors can currently destroy the selected session.
6. Risks: temporary unreadable layouts must not produce fabricated/stale analysis or capture another conversation. App exit, explicit stop/pause, consent revocation and service shutdown still require cleanup. Device UI verification must use fictional chats or TEMPER-owned screens only.
7. Scope: separate temporary layout recovery from session termination, retain verified conversation identity safely across window changes, draggable analysis companion with saved/clamped placement and reliable tap/popup gestures, regression tests, version 0.44.0 and updated candidate packaging.
8. Non-goals: new host adapters, universal model accuracy claims, reading hidden/background chat history, real feedback collection, a model upgrade, cloud deployment or changes to purchase configuration.
9. Acceptance: keyboard/composer changes recover without rearming; unreadable text is clearly unavailable while recovery remains enabled; explicit stops and actual host exit stop capture; another conversation is rejected before reading its messages; dragging does not open the popup or reset on updates; placement/popup fit the available screen; builds and meaningful fictional regression checks pass.
