# TEMPER 0.47.0 — Avatar home and interaction

The Android home follows the supplied interaction reference: a horizontal character
strip with a fixed center, a larger selected character on a subtle platform, a
single power switch, a status pill and one overlay preview surface. Settings is a
small secondary icon. There are no shop, currency, locked-card or dashboard panels
on this home.

The five prototype characters are Nova, Kai, Astra, Mira and Volt. Their original
vector artwork is generated by `scripts/generate-studio-avatars.py`. It produces
editable SVG for Figma and Android VectorDrawable resources from the same paths.
Android renders all eight expressions over the shared artwork. `studio_nova` is
distinct from the historical paid `nova` product ID. Verified already-owned legacy
companions remain available in the carousel; this UI grants no paid entitlements.
A previous free Alex selection migrates to the new Astra starter. Cosmetic choice
persists independently of power and is used by both floating overlay paths.

Swipe or use the arrows to select. Drag positions, scale and opacity interpolate
continuously; release snaps to a center in 300 ms. Touch cancellation, a second
pointer, animation interruption and detachment settle safely. TalkBack and keyboard
navigation can choose avatars. At most seven character views are reused per frame,
so layout/drawing work is constant with catalog size; catalog storage is O(n).
Adding catalog entries does not require editing carousel positions or screen layout.
The body asset API accepts Android Drawable resources, including vector, PNG and
WebP artwork; replacement assets should preserve the documented face anchors if
they use the procedural expression layer.

The master switch uses a 112 × 60 dp target. OFF dims/desaturates the hero; ON
illuminates it. The existing one-time consent, offline model download, overlay
permission and Accessibility setup still precede activation. Once ready, ON starts
the companion and automatic supported-chat analysis; OFF stops them. Selection
alone cannot activate reading. Ratings remain optional in Settings. The spectrum
still contains eight estimates and two short summaries, with the new surface and
accent colors. Model weights and capture boundaries are unchanged in this phase.

## Figma

[Editable design and prototype](https://www.figma.com/design/YyV1MhtSXYbI6u6Qjzyyd7)

- `01 – Temper UI`: Astra OFF/ON, Mira ON, Kai OFF and an illustrative fictional
  chat overlay. The overlay values are examples, not measured model outputs.
- `02 – Components`: the requested reusable Header, StatusPill, AvatarCarousel,
  AvatarItem, SelectedAvatar, AvatarPlatform, MasterToggle and InfoPanel, plus
  five editable artwork components. Variants and image/name/subtitle properties
  support reuse. Colors and key spacing/radius/type properties use shared tokens.
- `03 – Prototype`: all five avatars in OFF and ON states, forward/reverse arrows,
  avatar selection, drag-to-next and power transitions using Smart Animate.
- `04 – Design Tokens` is a labeled section on the Components page: the account's
  Starter plan rejected a fourth page. It includes 23 variables, four Roboto type
  styles, palette swatches, spacing, radii, motion and implementation notes.

Figma shows state transitions. Continuous pointer tracking and velocity-dependent
snapping are implemented and tested in Android. The final extra prototype audit
was refused by the Starter MCP quota, after successful creation of the linked
prototype and a structure/font/composition check of the home. No flattened UI
screenshot substitutes for editable components; the inspected home had 261 vector
nodes, 19 instances, 17 text nodes and zero raster image fills.

`design/phase47/tokens.json`, artwork, builder scripts, node ledger and generated
own-app screenshots accompany the implementation. Screenshots labeled ON are
rendering fixtures, not evidence that the user's real chat was analyzed.

## Verification

Native checks cover continuous dragging and exact settling, persistence and shared
overlay selection, forward/reverse moves, cancellation, a 51-entry catalog with
seven views, widths 320/390/430 dp at font scales 1.0/1.3, all nine historical and
new avatars × eight expressions, consent gating and one-tap OFF. Existing dummy
overlay/keyboard/popup, model continuity, complex English/Hinglish fixtures and
foundation privacy/consent checks are retained. Small widths with enlarged text
can scroll vertically; controls and text do not require horizontal scrolling.

This is a testing build and unsigned review bundle. Existing publishing, server,
signing, adapter support and real-world accuracy limitations remain in the release
documentation.
