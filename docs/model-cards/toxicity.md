# Dedicated toxicity classifier

Source: [unitary/toxic-bert](https://huggingface.co/unitary/toxic-bert), revision `4d6c22e74ba2fdd26bc4f7238f50766b045a0d94`, Apache-2.0 as declared by the author. Retain the downloaded upstream README and Apache license alongside local artifacts. This is the pinned Hugging Face checkpoint; its author states it differs from the latest [Detoxify library](https://github.com/unitaryai/detoxify). No latest-version equivalence is claimed.

Actual architecture: BERT sequence classifier, 12 layers, hidden size768, vocabulary30522. Six independent sigmoid outputs in configured order: toxic, severe_toxic, obscene, threat, insult, identity_hate. They do not sum to one. The existing toxicity channel receives toxic; insult and threat are additive inspectable channels. Hostility=max(insult,threat) is an explicit HEURISTIC proxy, not a separately trained class. No aggressive-tone class is invented.

Original safetensors SHA256: `2c272885d24138df70bff1b3cd944a999bd6b41dad33209730aa8ba074f6ad09`. Own ONNX export: `ba63edc8227e02f5aa9ee014d418c33de921a9232d0ac0210cbf19e451bcccf6`. Matching original uncased WordPiece vocabulary equals the pinned google-bert/bert-base-uncased vocabulary; its fast tokenizer JSON SHA256 is `ce64fce797c24f68df90b40a3f74f579b336a493db14bd583fd520ea0d8c9a98`. All source hashes/revisions are checked by scripts/download-toxicity.ps1. Runtime metadata is backend/src/main/resources/models/toxicity.json; no model binary is committed.

Export with scripts/export-toxicity.py and the pinned scripts/model-export-requirements.txt environment. CPU PyTorch/eager evaluation, dynamic batch/sequence, opset17, token_type_ids zero baked into the graph. ONNX checker and original-logits parity pass at 1e-4 for benign, insult and threat examples. Native Java probabilities independently match those references and reuse the session. The model runs locally via ONNX Runtime with verified artifacts, bounded512-token input, causal speaker-tagged history, and no hosted inference.

Trained on Jigsaw Wikipedia comment toxicity data. Scores are uncertain language estimates, not calibrated findings about intent or internal state; quoted speech, humor, identity mentions and domain shift can produce false positives. Speaker/history formatting has not been dialogue-validated. Unconfigured model retains explicitly marked fixtures; configured model failures do not silently fabricate scores. Enable with TEMPER_TOXICITY_MODEL_DIR. Genuine browser gate: TEMPER_REAL_TOXICITY_TEST=1.
