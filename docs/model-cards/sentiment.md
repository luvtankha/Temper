RobertaForSequenceClassification,12 layers/12 heads/768 dimension,50265-token case-sensitive byte BPE. Official config labels0negative,1neutral,2positive verified by export assertions. Original vocab/merges create RobertaTokenizerFast (transformers4.55.4/tokenizers0.21.4); serialized tokenizer feeds native DJL Java. scripts/export-sentiment.py exports ONNX opset17 with dynamic batch/sequence and eager attention using torch2.8.0 CPU. Model classifier pooler tensors are unused by the original Hugging Face classifier; no randomly initialized classification head is accepted. onnx.checker and three positive/negative/neutral PyTorch-vs-ONNX logits checks pass at1e-4 absolute/relative tolerance. Java then verifies native three-class output. Canonical backend/resources/models/sentiment.json pins exported modelSHA29774d57637d3082494f8878bf700824d1c6777051d4fc36ae556231cd75ec1f and tokenizerSHA727009a8214ddfa5af1deedf1006d4d06e8e51e54aa5f03566263d4e19bfcdce. Startup fails on mismatched hashes.

Input policy: current speaker-tagged message first, then up to five causal preceding turns oldest-first, each history text limited to240 characters. HTTP URLs become http; mentions become @user, following upstream preprocessing. Tokenizer max512 right-truncation including special tokens. Current-first retains its beginning; lengthy current text may leave little or no prior history after truncation. This is a documented engineering use of a tweet classifier, not a conversation-trained or validated dialogue model. Inputs/outputs are not logged or sent to a hosted API. Probabilities are not calibrated psychological confidence. English/Twitter training domain and bias limits apply; context sensitivity does not imply reliable pragmatic interpretation of short replies.

Integration: local TextClassifier reusable singleton, no inference on the message delivery path. Existing explicit analyze endpoint replaces signed sentiment with positive-minus-negative and signals.negativeSentiment with negative probability. Probabilities/model/tokens/context policy are inspectable in MODEL evidence. All six emotion values, other linguistic signals, conflict and turning points remain explicitly MOCK until subsequent phases. Result/snapshot mode HYBRID; no model failure silently substitutes fixtures when configured. Absent TEMPER_SENTIMENT_MODEL_DIR retains default MOCK mode and healthNONE. Configured healthHYBRID. UI labels partial provenance and preserves fixture labels on unreplaced charts.

Setup: create separate export Python environment, install scripts/model-export-requirements.txt (CPU torch wheel may use https://download.pytorch.org/whl/cpu); run scripts/download-sentiment.ps1 with Destination and Python. Binary conversion setup is separate from Java production runtime. Set TEMPER_SENTIMENT_MODEL_DIR and start Java21. Dedicated genuine tests: mvnw.cmd -Dtest=SentimentIntegrationTest test. Default verify intentionally skips artifact-dependent tests; it does not pretend model absence is a successful inference check.
